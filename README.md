# AE006 — Quiz με μόνο σωστή απάντηση

Αυτόνομη έκδοση παρόμοια με το **AE007** (Unit Linked + ασφαλιστικός πράκτορας), με μία βασική διαφορά στη ροή εξάσκησης:

- Οι ερωτήσεις οργανώνονται **ανά ενότητα / κεφάλαιο** όπως στο AE007.
- Σε κάθε ερώτηση εμφανίζεται **μόνο η σωστή απάντηση** (όχι οι τέσσερις επιλογές α/β/γ/δ).
- **Δεν** υπάρχει τυχαία σειρά απαντήσεων (αφαιρέθηκε το σχετικό checkbox).
- **Δεν** υπάρχει κουμπί «Θεωρία Ενότητας» ούτε φάκελος `theoria/`.
- Χωρίς σχόλιο «σωστά/λάθος» κάτω από κάθε ερώτηση.
- Μετάβαση μόνο με **Προηγούμενο · Επόμενο · Έξοδος** (η σωστή απάντηση φαίνεται αμέσως, χωρίς «Συνέχεια»).
- Η τυχαία σειρά **ερωτήσεων** παραμένει προαιρετική.

## Κατηγορίες Quiz

1. **Unit Linked** — τράπεζα `questions_bank.json` ανά κεφάλαιο UL.
2. **Ασφαλιστικός πράκτορας** — ύλη `insurance_agent_yli/` ανά θεματική ενότητα.

## Παραγωγή / συγχρονισμός

Η πηγή UI είναι το `AE007/index.html`. Μετά από αλλαγές στο AE007:

```bash
python3 AE006/build_ae006.py
```

Το script ξαναγράφει το `AE006/index.html` και συγχρονίζει `questions_bank.json`, `insurance_agent_yli/`.

## Τοπική εκτέλεση

```bash
cd AE006
python3 -m http.server 8767 --bind 127.0.0.1
```

Άνοιγμα: `http://127.0.0.1:8767/`

## Δομή

| Αρχείο / φάκελος | Ρόλος |
|------------------|--------|
| `index.html` | Εφαρμογή (παράγεται από AE007 + patches AE006) |
| `questions_bank.json` | Ερωτήσεις Unit Linked |
| `insurance_agent_yli/` | Ερωτήσεις πράκτορα |
| `build_ae006.py` | Script παραγωγής |
